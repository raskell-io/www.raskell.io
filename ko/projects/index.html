26 개 프로젝트

프로젝트

벤처, 대표 프로젝트, 실험실의 실험들. 실제 사용자와 운영을 염두에 둔 작업, 그리고 그저 흥미로워서 하는 몇 가지 곁가지 프로젝트입니다.

벤처

실제 회사로 자라 가는 초기 단계의 벤처입니다. 실제 사용자와 실제 책임이 있으며, 초기 사용자와 투자자와의 대화에 열려 있습니다.

투자 유치 중

초기 벤처를 지원해 주십시오.

엔젤, 벤처, 전략적 투자자를 환영합니다. 오픈 소스 프로젝트는 GitHub Sponsors, Open Collective, Ko-fi를 통한 후원도 받습니다.

투자 방법오픈 소스 후원
  • 공개 베타

    Archipelag.io 탈중앙화 AI 컴퓨팅입니다. AI 작업이 커뮤니티가 운영하는 GPU 호스트 네트워크에서 실행됩니다. 작업은 가까운 호스트와 선호 지역을 우선하고, 모든 작업은 어디서 실행되었는지 기록합니다. 엄격한 지역 제한은 개발 중입니다. 현재 무료 공개 베타로, 계량 기능을 검증하는 동안 호스트는 가상 크레딧을 받으며 실제 금전 지급은 아직 열리지 않았습니다.

    웹사이트
  • 공개 알파

    Cyanea 정말로 다시 실행되는 생물정보학 노트북입니다. 브라우저에서 WebAssembly로 실행되는 분석을 아무것도 설치하지 않고 작성하고, 실행하고, 공유할 수 있습니다. 모든 노트북, 데이터셋, 출력은 다시 실행할 수 있는 버전 관리된 스냅샷입니다. 그 아래에는 Rust 분석 스택이 있고, 21가지 파일 형식이 내장되어 있습니다. 오픈 소스이며, 셀프 호스팅과 연합 기능이 준비 중입니다.

    웹사이트
  • 개발 중

    Humankind 세대를 넘어 한 사람의 존재감을 보존하는 인간 연속성 플랫폼입니다. Humankind는 목소리, 이야기, 기억, 가치관, 관계의 온기로 이루어진 살아 있는 기록을 만들도록 도와, 거리나 노화나 죽음이 지워 버렸을 한 사람의 결을 오래도록 만날 수 있게 합니다. 동의를 우선하고, 기본적으로 개인정보를 보호하며, 기록된 사실과 재구성과 추론의 차이를 분명히 밝힙니다.

    웹사이트
  • 출시 중

    Arcanist AI가 코드를 쓰는 시대를 위한 Haskell 도구입니다. hx는 Rust로 만든 빠른 패키지 및 프로젝트 관리자이고, bhc는 검사할 수 있는 모든 것을 검사하도록 만든 컴파일러입니다. 무엇이 검증되었는지 기록하는 레지스트리와 함께, 사람이든 모델이든 같은 것을 두 번 검증할 필요가 없는 공유 자원을 향합니다.

    웹사이트

대표 프로젝트와 본격적인 작업

운영을 목표로 유지하는 인프라, 도구, 시스템입니다. 제가 반복해서 부딪히는 실제 문제를 풉니다.

  • 안정

    Zentinel 자유로운 웹을 지키기 위해 만든 보안 우선 리버스 프록시입니다. Cloudflare의 Pingora 위에서 Rust로 동작하며, 숨겨진 기본값보다 명시적인 설정을 택하고, WAF, 인증 및 기타 정책을 격리된 에이전트에서 실행하므로 에이전트가 멈춰도 프록시는 계속 동작합니다. WAF, 봇 관리, 신원, API 검사, 스크립팅을 위한 에이전트, Rust부터 Haskell까지의 SDK, 순수 Rust ModSecurity 엔진, 플릿 컨트롤 플레인을 제공합니다.

    웹사이트
  • 운영 중

    hx 빠른 바이너리 하나에 담은 Haskell 툴체인입니다. hx는 GHC와 Cabal을 설치하고, 코드를 빌드, 테스트, 포맷, 린트하며, 모든 의존성을 해시로 고정하고, 패키지를 배포합니다. Rust로 작성되어 몇 밀리초 만에 시작하고, 이미 쓰고 있는 .cabal 파일과 Hackage와 함께 동작하며, MCP를 통해 AI 에이전트에게도 같은 명령을 제공합니다.

    웹사이트
  • 베타

    bhc Basel Haskell Compiler는 여러분이 이미 쓰고 있는 Haskell을 위해 처음부터 새로 만든 컴파일러입니다. Rust로 작성되었고 LLVM을 통해 네이티브 코드로, 그리고 WebAssembly로 컴파일하며, 빌드마다 런타임 프로필을 고릅니다. Pandoc의 221개 모듈을 모두 컴파일하고, Pandoc의 Markdown 리더와 HTML 라이터가 처음부터 끝까지 실행됩니다.

    웹사이트
  • 운영 중

    broodwar.live 스타크래프트: 브루드 워 경쟁 플레이를 위한 커뮤니티 플랫폼으로, 브루드 워판 basketball-reference.com입니다. 영어와 한국어로 된 프로게이머 150명의 프로필, 모든 종족전의 빌드 오더, 대회, 위키, 그리고 브라우저에서 WebAssembly로 실행되어 아무것도 업로드하지 않는 리플레이 분석을 제공합니다.

    사이트 열기
  • 개발 중

    Refrakt Gleam을 위한 관례 우선 웹 프레임워크입니다. Phoenix처럼 생산적이고, Gleam처럼 명시적이며, Wisp 및 Lustre와 조합할 수 있습니다. 풀스택 코드 생성, CRUD 스캐폴딩, 그리고 BEAM 위에서 필요한 것을 모두 갖춘 개발 경험을 제공합니다.

    웹사이트
  • 개발 중

    Vela 베어메탈에서 중단 없이 앱을 배포합니다. 바이너리 하나, 컨테이너 없음. Heroku, Fly.io, Coolify, Kamal을 대신하는 셀프 호스팅 PaaS입니다. Rust로 만들었고, 무중단 배포와 내장 리버스 프록시를 갖추고 있습니다.

    웹사이트

공공과 연구

개방형 표준, 근거, 시스템적 사고를 공공의 삶, 역사, 그리고 인간 집단 연구에 적용합니다.

  • 운영 중

    Die Zukunft 공공의 삶에 공학 원칙을 적용하는 스위스의 운동으로, 좌도 우도 아닙니다. 개방형 표준을 통한 디지털 주권, 감사할 수 있고 이전할 수 있는 공공 인프라, 근거에 기반한 정책을 추구하며, 스위스 연방 데이터를 위한 자체 연구 파이프라인을 갖추고 있습니다.

    웹사이트
  • 매우 초기
    H

    Human Macroscope

    개인과 가족에서 제도, 문화, 문명에 이르기까지 여러 규모에 걸쳐 인간과 인간 집단을 다루는 장기적인 학제 간 연구 프로젝트입니다. 개인의 특성, 역할, 관계, 문화적 전승이 어떻게 결합해 창발적인 집단적 속성이 되는지를 탐구합니다.

  • 초기 프로토타입
    C

    Chronicle of Earth

    역사와 지정학을 다루는 인터랙티브 지도책으로, 1900년부터 2026년까지에서 시작합니다. 초기 프로토타입은 마을과 거리까지 확대되는 3D 지구본과 며칠에서 수십 년에 이르는 타임라인을 짝지었습니다. 데이터 모델은 사건, 영토 주장, 실효 지배, 출처, 불확실성을 구분해 기록합니다. 역사 데이터는 아직 작은 초안 모음이며, 상세 기본 지도는 현재의 지리를 보여 줍니다.

    SvelteKitTypeScriptMapLibre

실험실 / 취미 프로젝트

많은 아이디어를 시도하고, 작지만 실제로 동작하게 만들어 내놓은 뒤 어떤 것이 살아남는지 봅니다. 일부는 대표 프로젝트가 되고, 일부는 영원히 재미로 남습니다. 어느 쪽이든 부담은 없습니다.

  • 개발 중

    WASM-AD

    32비트 휴대용 게임기 하드웨어를 갖춘 판타지 콘솔 표준입니다. 타일 레이어, 스프라이트, 팔레트, 세이브 RAM이 카트리지 안에 메모리 매핑되어 있습니다. 카트리지 하나가 WebAssembly 모듈 하나입니다. 문서화된 명세, 적합성 테스트를 갖춘 참조 렌더러, Rust, C 및 C++, Zig, AssemblyScript, Go용 SDK, 웹 플레이어가 함께 제공됩니다.

    웹사이트명세
  • 개발 중

    coconutOS

    AI 추론을 위한 단단한 껍데기입니다. GPU 격리를 커널 기본 요소로 만드는 Rust 마이크로커널로, 모든 모델은 자체 페이지 테이블, VRAM 파티션, 권한을 가진 고유한 샤드에서 실행되고, GPU 드라이버는 ring 0 밖에 있으며, pledge_gpu와 unveil_vram은 권한을 줄이기만 합니다. 현재 QEMU에서 트랜스포머 순전파를 처음부터 끝까지 실행하며, 다음 단계는 실제 GPU 하드웨어입니다.

    이야기
  • 개발 중

    Terrarium

    LLM으로 움직이는 에이전트들이 창발적인 문명을 이루는 사회 시뮬레이션 엔진입니다. 각 에이전트는 성격, 욕구, 기억, 그리고 틀릴 수도 있는 믿음을 가집니다. 여러분이 세계의 규칙을 정하면, 시장과 위계와 동맹이 스스로 생겨나는 모습을 지켜볼 수 있습니다.

    웹사이트
  • 운영 중

    Hotaru

    60전극 어레이 위의 시뮬레이션된 뉴런 배양체가 DishBrain 실험처럼 브라우저에서 퐁을 합니다. 맞혔을 때와 놓쳤을 때의 피드백만으로는 실력이 늘지 않았습니다. 패들이 공 쪽으로 움직이면 조용해지는 입력은 효과가 있었고, 페이지는 이를 대조군과 나란히 보여 줍니다.

    실험 실행
  • 플레이 가능

    Kishi Rust로 작성하고 WebAssembly로 컴파일한 엔진을 상대로 체스, 쇼기, 바둑을 둡니다. 엔진은 브라우저 안에서 여러분의 기기로, 오프라인으로 두며, 초보자 수준부터 최고 실력까지, 조용한 판 위에서 대국합니다.

    플레이
  • 개발 중

    Sango

    현대 웹을 위한 엣지 진단 도구입니다. 명령 하나로 엔드포인트를 종합 분석하는 운영자 수준의 CLI입니다. TLS 검사, HTTP 프로토콜 감지(HTTP/1.1, HTTP/2, HTTP/3), 보안 헤더, 지연 시간 측정, 기술 스택 식별을 수행합니다.

    웹사이트
  • 개발 중
    C

    Conflux

    스키마를 인식하는 설정 상태 조정 도구입니다. 여러 작성자, 결정적 병합, git 마일스톤을 지원합니다. 저장소 백엔드(SQLite, PostgreSQL, DynamoDB)를 바꿔 끼울 수 있는 CRDT 문서 엔진입니다.

  • 개발 중
    S

    Shiioo (CO)

    가상 회사 OS입니다. DAG 워크플로, 이벤트 소싱, MCP 도구, 그리고 git에서 가져올 수 있는 분류된 스킬 레지스트리를 갖춘 에이전트 기반 엔터프라이즈 오케스트레이터입니다.

  • 개발 중

    Ushio

    WAF와 프록시의 동작을 이해하기 위한 결정적인 엣지 트래픽 재생 도구입니다. 트래픽을 HAR 파일로 캡처하고, 스테이징과 프로덕션 비교를 위해 URL을 다시 쓰고, 헤더를 변경하고, 쿠키를 제거하고, 환경별 WAF 응답을 비교합니다.

  • 개발 중
    D

    앰비언트 사운드스케이프 플랫폼입니다. 조합할 수 있고, 위치를 인식하며, AI로 만드는 배경 음악입니다.

  • 매우 초기
    r

    robogym

    로봇 에이전트를 훈련하기 위한 Rust/Bevy PWA입니다. 브라우저 기반 시뮬레이션으로 로보틱스를 누구나 접할 수 있게 합니다.

  • 진행 중

    Learn You the Web

    웹이 실제로 어떻게 동작하는지 알려 주는 친절한 안내서입니다. 이번에는 정말로요. HTTP, DNS, TLS, 그리고 이 모든 것을 이어 주는 프로토콜을 얼버무리거나 지나치게 단순화하지 않고 설명합니다.

Raskell

Raskell은 웹 위의 제 작은 공간이자, 제가 만드는 모든 것으로 들어가는 문입니다. 이곳에서는 플랫폼 자동화, 엣지 시스템, 응용 보안, 그리고 AI가 코드 대부분을 쓰게 되면서 달라지는 것들에 대해 씁니다.

보안 우선 리버스 프록시부터 Rust로 만든 Haskell 도구까지, 제가 빠져드는 프로젝트들은 실제로 만들어지기 전에 먼저 이 페이지에 메모로 등장합니다. 이름은 rascal × Haskell × Raffael입니다.
