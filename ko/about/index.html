소개

Raffael은 바젤의 AI 아키텍트로, 엔터프라이즈 AI와 에이전트 플랫폼, 엣지 시스템, 응용 보안을 다룹니다.

안녕하세요, Raffael입니다. 바젤에 살고 있으며 AI 아키텍트로 일하고 있습니다.

낮에는 Helvetia Baloise Group에서 AI 플랫폼과 에이전틱 AI를 담당하는 엔터프라이즈 솔루션 아키텍트로 일합니다. 그룹 전체의 AI 플랫폼을 정의하는 일을 돕고 있습니다. 서로 다른 기술 전략을 가진 여러 시장 단위가 파운데이션 모델, 에이전트, AI 지원 엔지니어링을 안전하고 통제된 방식으로 쓸 수 있도록 하는 공통 기반입니다. 그 전에는 2026년 상반기 동안 같은 회사에서 안전한 웹 전송과 엣지 인프라를 맡은 플랫폼 엔지니어로 일했습니다. 그때 동료 한 명과 함께, 시끄러운 ModSecurity 경보를 운영자가 바로 처리할 수 있는 검토 항목으로 바꿔 주는 LLM 지원 워크플로를 만들었습니다.

일 밖에서는 보안과 AI가 만나는 지점에서 자동화 우선 플랫폼과 엣지 시스템을 만들고, 그 밖에도 많은 것을 만듭니다. 프로그래밍 언어 도구, 로컬 우선 앱, 시뮬레이션, 게임 같은 것들입니다. 오랫동안 제 아이디어는 시도해 볼 시간이 없어서 공책 속에만 머물렀습니다. AI가 병목을 코드 작성에서 무엇을 만들 가치가 있는지 정하는 일로 옮겨 놓았기 때문에, 이제는 아이디어를 작고 실제적인 형태로 내놓고 어떤 것이 살아남는지 지켜봅니다. 이곳의 글은 제 개인의 견해이며 고용주의 입장이 아닙니다.

raskell=rascal×Haskell×Raffael(너구리 마스코트 포함)

사람을 돕는 기술. 기본은 단순하게, 필요할 때는 정밀하게.

저는 어려운 문제를 좋아합니다. 지연 시간, 신뢰성, 위험, 그리고 사람이 한꺼번에 부딪히는 문제 말입니다. 응용 보안은 그런 무대 가운데 하나일 뿐입니다. 적대적인 입력과 미심쩍은 신호 대 잡음비 속에서 압박을 받는 시스템입니다.

제 아이디어는 대부분 읽기에서 시작합니다. 책, 논문, 긴 글이며, 그중 많은 것이 제 분야와 멀리 떨어져 있습니다. 지금 읽는 것, 다음에 읽을 것, 이미 읽은 것을 독서 기록(영어)에 남기고, 어떤 책에 대해 구체적으로 할 말이 있을 때 서평을 씁니다.

하는 일

  • AI 및 에이전트 플랫폼 모델 게이트웨이, 오케스트레이션, 컨텍스트, 메모리, 도구 사용, 거버넌스, 관측 가능성.
  • 플랫폼 자동화 워크플로, 가드레일, 셀프서비스, 운영 용이성.
  • 엣지 시스템 리버스 프록시, 정책, 관측 가능성, 안전한 변경.
  • 응용 보안 잡음을 줄이고, 사람이 효과적으로 일하게 하고, 실용적인 통제를 내놓습니다.
  • AI 지원 엔지니어링 에이전트 워크플로, 모델 기반 도구, 운영 자동화.
  • 언어와 도구 컴파일러, 패키지 관리자, 프레임워크, 명세.
  • 로컬 우선 앱 데이터를 여러분의 기기에 두는 소프트웨어.
  • 시뮬레이션과 게임 실제 세계를 닮은 것도, 놀이를 위해 만든 것도 있는 상호작용 세계.
  • 개방형 표준 벤더 종속보다 지속 가능한 해법.

  • Stable

    Zentinel Security-first reverse proxy built to guard the free web. Rust on Cloudflare's Pingora, explicit configuration over hidden defaults, and WAF, auth and other policy in isolated agents, so a crashing agent leaves the proxy running. Agents for WAF, bot management, identity, API inspection and scripting, SDKs from Rust to Haskell, a pure Rust ModSecurity engine and a fleet control plane.

    Website
  • Open beta

    Archipelag.io Decentralized AI compute: AI jobs run on a network of community-operated GPU hosts. Jobs prefer nearby hosts and a preferred region, and every job records where it ran; strict regional enforcement is in development. In free open beta: hosts earn virtual credits while metering is validated, and real-money payouts are not enabled yet.

    Website
  • Public alpha

    Cyanea Bioinformatics notebooks that actually re-run. Write, run, and share analyses that execute in your browser on WebAssembly, with nothing to install. Every notebook, dataset, and output is a versioned snapshot you can run again. A Rust analysis stack underneath, 21 file formats built in. Open source, with self-hosting and federation on the way.

    Website
  • Shipping

    Arcanist Haskell tooling for the age of AI-authored code. hx is a fast package and project manager written in Rust, and bhc is a compiler built to check everything it can. With a registry that records what has been verified, they lead toward a commons where nobody, human or model, has to verify the same thing twice.
