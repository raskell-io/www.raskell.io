投资

开放天使投资和风险投资的创业项目，以及可以通过 GitHub Sponsors、Open Collective 或 Ko-fi 支持的开源项目。

我构建的一些东西开放投资。它们分为两类，支持的方式也不同。有些项目，比如 Arcanist，两者都是。

  1. 创业项目 正在成为公司的路上，有真实的用户和面向生产的意图。开放天使投资、风险投资和战略投资。查看创业项目
  2. 开源项目 首先是公共物品，靠赞助维持。其中较大的项目也欢迎投资洽谈。查看如何赞助

创业项目

我希望发展成公司的早期创业项目。我在寻找理解早期基础设施和深度技术产品的天使投资人、基金和战略合作伙伴。

  • 公开测试

    Archipelag.io 去中心化的 AI 算力：AI 任务运行在由社区运营的 GPU 主机网络上。任务优先选择就近的主机和首选地区，每个任务都会记录它在哪里运行；严格的地区约束正在开发中。目前为免费公开测试：主机在计量功能验证期间获得虚拟积分，真实货币结算尚未开放。

    阅读项目简介
  • 公开 Alpha

    Cyanea 真正能重新运行的生物信息学笔记本。编写、运行并分享在浏览器中用 WebAssembly 执行的分析，无需安装任何东西。每个笔记本、数据集和输出都是一个可以再次运行的版本化快照。底层是 Rust 分析栈，内置 21 种文件格式。开源，自托管和联邦功能即将推出。

    阅读项目简介
  • 开发中

    Humankind 一个跨越世代保存一个人存在感的人类延续平台。Humankind 帮助人们建立一份由声音、故事、记忆、价值观和人与人之间的温情组成的活档案，让一个人的质感在距离、衰老或死亡本会将其抹去之后，依然可以被触及。同意优先，默认保护隐私，并明确区分记录下来的事实、重建和推断。

    阅读项目简介
  • 交付中

    Arcanist 面向 AI 编写代码时代的 Haskell 工具。hx 是用 Rust 写的快速包与项目管理器，bhc 是一个尽可能检查一切的编译器。再加上一个记录哪些内容已被验证的注册中心，它们通向一个公共资源：无论是人还是模型，都不必把同一件事验证两次。

开源项目

应当始终免费使用的基础设施和工具。赞助用于维护、发布，以及让它们保持健康所需的时间。Open Collective 公开所有收入和支出；GitHub Sponsors 和 Ko-fi 适合按月或一次性的支持。依赖某个项目或想在其上构建的公司，也欢迎来谈投资。

致天使投资人和基金

我接受的方式

  • 天使轮和种子前轮 在单个创业项目中的早期投资，来自希望贴近工作本身的人。
  • 风险投资 面向已经准备好在首批用户之外扩张的创业项目。
  • 战略投资 来自使用某个项目或在其上构建的公司。
  • 企业规模的赞助 面向开源项目，可附带或不附带股权。

我可以分享的内容

视创业项目及其阶段而定：

  • 演示 产品的完整讲解，以及在有测试版或 Alpha 版时的访问权限。
  • 路线图 创业项目的方向，以及一笔投资将为什么提供资金。
  • 数据 在阶段允许的范围内，提供使用量和增长数据。
  • 架构 它是如何构建的。大部分代码已经在 GitHub 上公开。
  • 路演材料 对话开始之后，还有更多材料。

如何联系

  1. 你是谁 以及你是以天使投资人、基金还是公司的身份投资。
  2. 你感兴趣的是什么 哪个创业项目或项目，以及原因。
  3. 金额和阶段 你通常的投资金额，以及你投资的阶段。
  4. 你首先需要什么 在通话之前你希望看到的任何内容。
