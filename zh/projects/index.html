  • 稳定

    Zentinel 为守护自由 Web 而构建的安全优先反向代理。基于 Cloudflare Pingora 的 Rust 实现，明确的配置优先于隐藏的默认值，WAF、认证和其他策略运行在隔离的智能体中，因此某个智能体崩溃时代理仍会继续运行。提供 WAF、机器人管理、身份、API 检查和脚本等智能体，从 Rust 到 Haskell 的 SDK，一个纯 Rust 的 ModSecurity 引擎和一个集群控制平面。

    网站
  • 已上线

    hx 装进一个快速二进制文件里的 Haskell 工具链。hx 负责安装 GHC 和 Cabal，构建、测试、格式化和检查你的代码，按哈希锁定每个依赖，并发布你的包。它用 Rust 编写，几毫秒内启动，兼容你已经在用的 .cabal 文件和 Hackage，还通过 MCP 为 AI 智能体提供同样的命令。
