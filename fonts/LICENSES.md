# Bundled typefaces

The `geist-*.woff2` files are subset builds of Geist, copyright Vercel, and the
`ibm-plex-mono-*.woff2` files are subset builds of IBM Plex Mono, copyright IBM
Corp. `jetbrains-mono-diagram.woff2` is a subset build of JetBrains Mono, copyright
The JetBrains Mono Project Authors, used for ASCII diagrams. All three typefaces are
distributed under the SIL Open Font License 1.1:
https://openfontlicense.org/open-font-license-official-text/

The CSS uses project-local family aliases and keeps system-stack fallbacks.
