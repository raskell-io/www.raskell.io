Projects

All projects →
  • Open beta

    Archipelag.io Decentralized AI compute: AI jobs run on a network of community-operated GPU hosts. Jobs prefer nearby hosts and a preferred region, and every job records where it ran; strict regional enforcement is in development. In free open beta: hosts earn virtual credits while metering is validated, and real-money payouts are not enabled yet.

    Website
  • Public alpha

    Cyanea Bioinformatics notebooks that actually re-run. Write, run, and share analyses that execute in your browser on WebAssembly, with nothing to install. Every notebook, dataset, and output is a versioned snapshot you can run again. A Rust analysis stack underneath, 21 file formats built in. Open source, with self-hosting and federation on the way.

    Website
  • Shipping

    Arcanist Haskell tooling for the age of AI-authored code. hx is a fast package and project manager written in Rust, and bhc is a compiler built to check everything it can. With a registry that records what has been verified, they lead toward a commons where nobody, human or model, has to verify the same thing twice.

    Website
  • Stable

    Zentinel Security-first reverse proxy built to guard the free web. Rust on Cloudflare's Pingora, explicit configuration over hidden defaults, and WAF, auth and other policy in isolated agents, so a crashing agent leaves the proxy running. Agents for WAF, bot management, identity, API inspection and scripting, SDKs from Rust to Haskell, a pure Rust ModSecurity engine and a fleet control plane.

    Website
