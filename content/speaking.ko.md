## 강연 {#talks}

발표 자료는 [발표 자료](@/talks/_index.ko.md)에 모아 두었습니다.

{% card(title="저는 코드 대부분을 더 이상 직접 쓰지 않습니다", url="/talks/iat-13-basel/", eyebrow="IT's ABOUT TECH #13, 바젤", meta="2026년 6월 10일 · FHNW Aula", links=["발표 자료 열기|/talks/iat-13-basel/", "행사 페이지|https://www.swissmadesoftware.org/en/news/2026/iat--13.html"]) %}
swiss made software의 IT's ABOUT TECH 저녁 행사에서 "손으로 하는 소프트웨어 엔지니어링은 어제의 일, 이제는 AI. 정말일까?"라는 주제로 진행한 15분짜리 쇼케이스입니다. 도구에 관한 강연이 아닙니다. Claude Opus 4.5와 Claude Code가 등장한 뒤 오랜 경력의 엔지니어에게 무엇이 달라졌는지, 그리고 병목이 더 이상 시간이 아니게 되었을 때 몇 년 묵은 아이디어 목록에 어떤 일이 일어나는지에 관한 이야기입니다.

**핵심 내용:**

- 병목은 생각을 문법으로 옮기는 일에서, 무엇을 만들지 그리고 결과가 받아들일 만한지 판단하는 일로 옮겨 갔습니다
- AI가 아이디어를 만들어 낸 것이 아닙니다. 이미 있던 아이디어가 공책 밖으로 나올 수 있게 해 주었습니다
- 사람은 사라지지 않았습니다. 사람은 스택의 더 위쪽으로 올라갔습니다
{% end %}

{% card(title="자가 학습 WAF: 생성형 AI로 ModSecurity 오탐 길들이기", url="https://path.rsaconference.com/flow/rsac/us26/FullAgenda/page/catalog/session/1753946922633001YdMq", eyebrow="RSAC 2026 · NCS-W01", meta="2026년 3월 25일 · Moscone Center, San Francisco", links=["RSAC 웹사이트에서 세션 보기|https://path.rsaconference.com/flow/rsac/us26/FullAgenda/page/catalog/session/1753946922633001YdMq"]) %}
OWASP Core Rule Set(CRS)을 사용하는 ModSecurity는 강력한 오픈 소스 WAF이지만, 오탐을 조정하는 일은 여전히 고통스럽고 시간이 많이 듭니다. 이 강연에서는 생성형 AI로 차단된 요청을 분석하고, 정당한 요청인지 판단하고, 조정 규칙을 자동으로 생성하는 자가 학습 방식을 소개했습니다. 수작업을 줄이면서도 승인 단계에는 사람이 계속 참여합니다.

**핵심 내용:**

- 생성형 AI가 WAF 오탐을 높은 정확도로 분류하는 방법
- 사람의 감독 아래 규칙을 자동으로 생성하는 실용적인 파이프라인
- 이 방식을 운영 환경에 적용하며 얻은 교훈

**언론용 요약:** 생성형 AI로 WAF 오탐을 자동으로 찾아내고 고쳐서, 조정의 골치 아픔 없이 ModSecurity를 효과적으로 유지합니다.
