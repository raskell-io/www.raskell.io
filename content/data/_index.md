Some of what I read turns into data before it turns into writing: who worked where, which idea came when. When it does, I publish the data here as well. Each dataset is one JSON file with a page beside it that says what a record is, what the fields mean, how I compiled it, and where it is thin. Some have a figure drawn from the file; some are only the file.

The data is yours to use under the licence named on each page. Attribute it to me and link the page.
