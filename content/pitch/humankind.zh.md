大多数家庭在两代人之内就会失去一个人的鲜活质感。试图留住它的工具，要么印一本书，要么做一个假装是某个人的聊天机器人。Humankind 是一个私密的、以同意为先的档案库，一个人和他的家人在这里收集声音、故事和回忆，而从这个档案库中得出的每一个回答，都会被标注为录制的、重构的或推测的。

## 问题 {#the-problem}

照片应用和家谱保存的是名字、日期和照片。它们留不住一个人讲故事的方式，留不住他觉得什么好笑，也留不住他会对孙辈说些什么。这些通常在一两代人之后就消失了，而当记忆开始衰退时，往往消失得更早。

{% tiles(cols=2) %}
- **父母日渐年迈的成年子女** 他们希望趁还有时间，把故事和声音留下来，常常是在确诊痴呆症这类疾病之后立刻开始。
- **分散在不同国家的家庭** 孙辈一年只能见祖父母几次，甚至根本见不到。
- **身患重病的人** 他们希望按照自己的意愿，留下一些真实的东西。
- **养老院和临终关怀机构** 它们已经在手工开展回忆和生命故事工作。这些成果很少以日后任何人都能使用的形式保存下来。
{% end %}

## 产品 {#the-product}

应用已经构建完成：一个基于 Elixir 和 Phoenix LiveView 的应用，用 Rust 处理音频、加密、图像处理和本地嵌入。

{% tiles(cols=3) %}
- **一个鲜活的档案库** 文字、音频、视频和照片，配有转录和引导式提示，提示哪些回忆还没有记录下来。
- **共享空间** 家庭成员可以贡献自己的回忆并署名，还可以设立负责照看档案库的监护人。
- **有据可依的人格** 对话只取材于档案库，并提供不同视角，比如一个人如何对孙辈说话，或者如何对学生说话。
- **经同意的声音** 可选的语音合成，使用本人自己的录音，并有单独的同意范围。
- **故事** 由带引用的回忆构成的叙事，可导出为 PDF 或 Markdown。
- **随时可以带走** 静态加密、彻底删除，以及整个档案库的导出。
{% end %}

## 市场 {#the-market}

各家市场报告的结论并不一致，有些还把数字遗产管理也算作“数字遗产”，因此这些数字只是背景参考，而不是 Humankind 所针对的市场。方向是一致的：人们愿意为保存家族记忆花真金白银，而这个品类正在增长。

{% tiles(cols=3, variant="figures") %}
- **150 亿至 250 亿美元** 2025 年全球数字遗产市场规模，每年增长约 14% 至 16%。[Mordor Intelligence, Precedence Research](https://www.mordorintelligence.com/industry-reports/digital-legacy-market)
- **73 亿美元** 2025 年家谱产品和服务市场规模，预计到 2032 年达到 166 亿美元。[Kings Research](https://www.kingsresearch.com/genealogy-products-and-services-market-29)
- **1.04 亿** 仅 MyHeritage 一家的注册用户数：家族记忆是一个大众市场。[Calcalist](https://www.calcalistech.com/ctechnews/article/syr4gmfmzl)
{% end %}

## 为什么是现在 {#why-now}

{% tiles(cols=2, variant="figures") %}
- **22 %** 2025 年欧盟 65 岁及以上人口所占比例，并且逐年上升。[Eurostat](https://ec.europa.eu/eurostat/statistics-explained/index.php/Population_structure_and_ageing)
- **5700 万** 全球痴呆症患者人数，每年新增病例近 1000 万。记忆必须在消退之前被记录下来。[WHO，经 NIHR 报道](https://www.dementiaresearcher.nihr.ac.uk/who-dementia-statistics/)
- **2.81 亿** 2024 年的国际移民人数。家人之间相隔得比以往任何时候都远。[IOM World Migration Report](https://ruralindiaonline.org/en/library/resource/world-migration-report-2024/)
- **2026 年 8 月** 欧盟 AI Act 针对聊天机器人和合成语音的透明度义务现已生效。Humankind 在设计上就会主动披露。[Cooley](https://www.cooley.com/news/insight/2026/2026-08-03-eu-ai-act-transparency-obligations-take-effect-2-august-2026)
{% end %}

转录、检索和语音合成也已经变得足够便宜，一个小团队就能做出过去获得融资的公司要花好几年才能做出的东西。

## 与众不同之处 {#what-sets-it-apart}

{% tiles(cols=2) %}
1. **每个回答都标明出处** 每一段回忆和每一个回答都被标注为录制的、重构的或推测的，另有一项独立的检查对照来源审核生成的文本。真实胜过流畅。
2. **可以审计的同意** 同意记录只追加、带版本，并为数据处理、人格对话、故事和声音分别设定范围。任何内容都不会被覆盖。
3. **家族档案，而非个人录音** 多个人为同一个档案库贡献内容，各自署名，监护人也无法改写一段回忆的来源。
4. **人格从不自称是那个人** 它会说明自己是什么，不会编造回忆，它是为保存而建，而不是为复活。
5. **在当事人在世时就有用** 如今家人已经在各自的圈子里分享故事。Humankind 并不只用于某人去世之后。
{% end %}

## 竞争 {#competition}

| 公司 | 他们做什么 | Humankind 的不同之处 |
|---|---|---|
| StoryWorth | 每周发送邮件提示，最后汇成一本印刷书 | 保留声音和媒体，接受全家人的贡献，并加入带溯源的人格 |
| Remento | 把口述故事变成书 | 一个鲜活的档案库，而不只是一本书；每个回答都引用来源 |
| HereAfter AI | 基于访谈、使用本人声音的生命故事虚拟形象 | 录制的、重构的和推测的内容都有标注；有同意范围和监护人 |
| StoryFile | 视频问答虚拟形象；2024 年申请了 Chapter 11 破产保护 | 低成本的异步记录和完整导出，档案库不依赖于公司的存续 |
| Project December | 根据一份关于任何人的问卷构建的聊天机器人 | 未经当事人或监护人同意，不会创建人格 |
| Ancestry, MyHeritage | 家谱、档案、DNA | 互为补充：它们记录一个人与谁有亲缘关系，Humankind 记录一个人是怎样的人 |

## 商业模式 {#business-model}

{% tiles(cols=3) %}
- **免费版** 一个档案库和有限次数的对话，让一个家庭无需做任何决定就能开始。
- **专业版** 不限数量的档案库、声音和故事导出。
- **家庭版** 为所有想贡献内容的人提供共享空间。
- **记录套餐** 当诊断到来、时间紧迫时购买的一次性套餐。
- **照护合作** 与已经在开展生命故事工作的临终关怀机构、养老院和痴呆症慈善组织进行试点。
- **长期保存** 付费的长期档次，保证可以导出，并提供档案托管。
{% end %}

免费版、专业版和家庭版已列入产品路线图。记录套餐、照护合作和长期保存档次，是接下来要与家庭一起检验的选项。

## 目前进展 {#where-it-stands}

- 应用已经构建并经过测试：档案库、同意、加密、溯源、人格、声音、故事和分享。
- 网站已经上线，并开放了抢先体验的候补名单。
- 下一步：在瑞士或欧盟区域进行生产部署，然后与候补名单中的家庭开展封闭测试。

目前还没有付费用户。这是一张早期入场券，投向一个已经存在、但市场还没有见过的产品。

## 风险 {#risks}

{% tiles(cols=2) %}
- **情感伤害** 关于“deadbot”的研究警告了操纵和依赖的风险。Humankind 要求获得同意，排除成瘾式设计和广告，并将增加让人格有尊严地退役的方式。
- **公众的怀疑** 许多人排斥用 AI 再现逝者。Humankind 的定位是保存，以及在生前分享，而不是与逝者对话。
- **监管** 有关逝者数据的规则因国家而异，AI Act 要求进行披露。有明确记录范围的监护人和会主动表明身份的人格可以同时回应这两点。
- **长久性** 一家记忆公司如果消失，会把记忆一起带走。完整导出现在已经可用；开放格式和托管已在计划之中。
{% end %}

## 资金将用于什么 {#what-funding-would-do}

{% tiles(cols=2) %}
1. **上线** 在瑞士或欧盟区域进行生产部署，配备备份和监控。
2. **封闭测试** 邀请候补名单中的家庭参与，并就他们保存什么以及为什么保存进行结构化访谈。
3. **照护试点** 与一到两家临终关怀或照护机构合作，并有一位伦理顾问参与。
4. **计费** 免费版、专业版和家庭版。
5. **信任** 针对合成语音的 AI Act 合规审查、开放的导出格式，以及档案托管。
6. **移动端记录** 一款可以离线录制声音和故事的应用，在对话发生的地方使用。
{% end %}
