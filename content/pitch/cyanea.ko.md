발표된 생물학 노트북 대부분은 더 이상 실행되지 않습니다. 1만 개가 넘는 노트북을 조사한 한 연구에서 같은 결과를 다시 낸 것은 열 개 중 하나도 되지 않았습니다. Cyanea는 각 분석을 정확한 데이터 및 버전과 함께 저장하고, 브라우저의 WebAssembly 위에서 또는 기관이 관리하는 노드에서 실행하므로 민감한 데이터가 밖으로 나갈 필요가 없습니다. 오픈 소스이며, 테스트를 거친 18개의 Rust 라이브러리 위에 만들어졌고, 현재 공개 알파 단계입니다.

## 문제 {#the-problem}

분석은 그것을 만든 사람보다 오래 살아남지 못합니다. 의존성은 바뀌고, 데이터 링크는 끊기며, 어떤 파일의 어떤 버전이 그림 하나를 만들어 냈는지 아무도 말하지 못합니다. 학생이 떠나면 그 작업도 함께 떠납니다.

{% tiles(cols=3) %}
- **학술 연구실** 책임 연구자 한 명과 몇 명의 연구원으로 이루어져 있으며, 심사자는 재현성을 요구하고 결과는 졸업 때마다 사라집니다.
- **코어 퍼실리티** 여러 고객 연구실에 분석을 제공하며, 넘겨줄 수 있고 근거를 댈 수 있는 버전 관리된 결과가 필요합니다.
- **바이오테크 팀** 5명에서 20명 규모의 작은 계산 그룹으로, 표준 분석과 감사 추적, 빠른 온보딩이 필요합니다. 첫 유료 구매자입니다.
- **컨소시엄과 제약사** 환자 데이터나 독점 데이터를 옮기지 않고 방법을 공유해야 하는 여러 기관입니다.
- **교육** 설치가 필요 없는 노트북과 학습 커리큘럼으로, 퍼널의 입구입니다.
{% end %}

## 제품 {#the-product}

{% tiles(cols=3) %}
- **Spaces** 데이터셋, 노트북, 프로토콜, 결과가 함께 버전 관리되며, 셀 단위의 diff와 복원을 지원합니다.
- **고정된 입력** 모든 데이터 파일은 SHA-256 해시로 저장되고, 결과는 그것을 만든 셀, 코드 버전, 데이터로 다시 연결됩니다.
- **브라우저에서 실행** 노트북 셀은 워커 안의 WebAssembly에서 실행되며, 설치할 것이 없습니다. 여섯 가지 브라우저 도구로 서열, 정렬, FASTQ, VCF, 트리를 살펴볼 수 있고, 파일은 컴퓨터 밖으로 나가지 않습니다.
- **Rust 분석 코어** Apache 라이선스의 크레이트 18개와 약 3,700개의 테스트로, 서열과 정렬부터 단일 세포, 계통학, 단백질체학까지 다룹니다.
- **21가지 포맷 내장** FASTA와 FASTQ부터 VCF, BAM, Parquet, PDB, Newick까지, 업로드할 때 인식하고 색인합니다.
- **팀을 위한 설계** 조직과 역할, 실시간 접속 표시, 웹훅을 갖춘 REST API, Jupyter 가져오기, ORCID 로그인을 지원합니다.
{% end %}

페더레이션을 통해 자체 호스팅 노드는 선택한 Spaces를 콘텐츠 해시 기반 매니페스트로 서로에게 게시할 수 있습니다. 그래서 방법은 이동하고 데이터는 제자리에 머뭅니다.

## 시장 {#the-market}

시장 보고서마다 생물정보학을 다르게 정의하므로, 이 수치는 참고용 배경입니다. 과학용 노트북만을 따로 다룬 신뢰할 만한 수치는 없으며, 이 페이지는 그런 수치를 지어내지 않습니다.

{% tiles(cols=3, variant="figures") %}
- **235억 달러** 2025년 전 세계 생물정보학 시장으로, 매년 13퍼센트 성장해 2030년에는 435억 달러에 이릅니다. [BCC Research](https://www.bccresearch.com/market-research/biotechnology/bioinformatics-technologies-and-global-markets-bio051g.html)
- **80억 달러** 2025년 계산생물학 시장으로, 2034년에는 227억 달러로 전망됩니다. [Global Market Insights](https://www.gminsights.com/industry-analysis/computational-biology-market)
- **42억 달러** 2025년 생물정보학 서비스 시장으로, 매년 16퍼센트 성장합니다. [Persistence Market Research](https://www.persistencemarketresearch.com/mediarelease/bioinformatics-services-market.asp)
{% end %}

## 왜 지금인가 {#why-now}

{% tiles(cols=2, variant="figures") %}
- **8.5 %** 생물의학 논문의 노트북 가운데 동일한 결과를 재현한 비율로, 10,388개 중 879개입니다. [GigaScience 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10783158/)
- **70 %+** 다른 과학자의 실험을 재현하는 데 실패한 적이 있는 연구자의 비율입니다. [Nature 설문](https://www.nature.com/articles/533452a)
- **2025/327** EU 보건 데이터 규정은 2차 활용을 위해 안전한 처리 환경을 요구하고, 스위스 법은 유전 데이터를 민감 정보로 다룹니다. 분석이 데이터에게 가야 합니다. [Belgian Health Data Agency](https://www.hda.belgium.be/en/news/regulation-european-health-data-space-published)
- **800+** Cyanea 바로 옆인 바젤 지역의 생명과학 기업 수입니다. [BaselArea](https://baselarea.swiss//wp-content/uploads/2023/01/Fakten-uber-die-Life-Sciences-DE_2025-1.pdf)
{% end %}

이제 WebAssembly는 브라우저에서 Rust를 네이티브에 가까운 속도로 실행합니다. Cyanea의 FASTA 파서는 초당 약 2.4 GB를 읽으며, 이는 BioPython보다 약 여섯 배 빠르고 결과는 자릿수까지 동일합니다. 또한 AI 덕분에 분석 코드가 저렴해질수록, 무엇을 무엇에 대해 실행했는지에 대한 신뢰할 수 있는 기록이 희소한 자산이 됩니다.

## 차별점 {#what-sets-it-apart}

{% tiles(cols=2) %}
1. **사용자가 있는 곳에서 실행** 분석은 아무것도 설치하지 않고 브라우저에서, 또는 기관이 관리하는 서버에서 실행됩니다.
2. **모든 입력을 고정** 콘텐츠 주소 기반 데이터와 버전 관리된 노트북 덕분에, 결과는 그것을 만든 것을 정확히 가리킵니다.
3. **데이터가 아니라 방법을 공유** 자체 호스팅 노드는 선택한 Spaces를 서로에게 게시하고, 환자 데이터는 있던 곳에 그대로 머뭅니다.
4. **어디서나 검증된 하나의 코어** 같은 Rust 크레이트가 서버와 브라우저, Python에서 실행되며, BioPython과 대조해 검증되었습니다.
5. **기본적으로 개방** 노드와 라이브러리는 Apache 2.0이며, 자체 호스팅 노드에는 요금제 제한이 없습니다.
{% end %}

## 비즈니스 모델 {#business-model}

오픈 코어 방식입니다. 자체 호스팅은 무료이고, 호스팅 허브는 자체 호스팅으로 대신할 수 없는 것에 요금을 받습니다. 결제와 요금제 제한은 이미 구현되어 있습니다.

{% tiles(cols=2, variant="figures") %}
- **0달러** Free: 공개 Spaces, 브라우저 실행, 1 GB.
- **98달러** Pro, 사용자당 월 요금: 비공개 Spaces, 100 GB, 서버 컴퓨팅 크레딧.
- **499달러** Team, 워크스페이스당 월 요금: 1 TB, 다섯 개의 좌석, 감사 내보내기.
- **1만 5천 달러 이상** Enterprise, 연간 요금: 온프레미스 또는 에어갭 배포와 지원.
{% end %}

시장 진출은 세 곳에서 다섯 곳의 설계 파트너로 시작합니다. 학술 연구실 두 곳과 바이오테크 그룹 한 곳이 각각 실제 분석 하나를 가져오고, 피드백을 주는 대가로 1년 동안 Pro 또는 Team 요금제를 무료로 사용합니다. 코어 퍼실리티, 그리고 데이터 저장 위치가 절대적인 조건인 스위스와 EU의 그룹이 자연스러운 첫 구매자입니다.

## 현재 상황 {#where-it-stands}

{% tiles(cols=3, variant="figures") %}
- **공개 알파** 호스팅 허브와 웹사이트가 cyanea.bio에서 운영 중입니다.
- **3,700** crates.io에 게시된 18개의 오픈 소스 Rust 크레이트 전체의 테스트 수입니다.
- **10** 분야별로 하나씩 미리 준비된 시작용 Spaces이며, 여기에 브라우저 도구 여섯 가지가 더해집니다.
{% end %}

아직 유료 고객이나 설계 파트너는 없습니다. Python과 R 셀은 받아들이지만 아직 실행되지 않으며, 자체 호스팅 노드는 앞으로 공개될 코어 라이브러리에 여전히 의존합니다. 자금은 가장 먼저 이 부분에 쓰입니다.

## 위험 요소 {#risks}

{% tiles(cols=2) %}
- **"브라우저 속 장난감"** 생물학자는 Python과 R로 작업합니다. Python 실행과 GB 규모의 서버 컴퓨팅이 최우선 과제이며, 서버 경로는 이미 존재합니다.
- **자체 호스팅이 비공개 코어에 의존** 코어 라이브러리 공개는 첫 엔터프라이즈 판매 전에 계획되어 있습니다.
- **페더레이션 신뢰** 현재 매니페스트는 콘텐츠 해시로 관리되며, 다음 단계는 암호학적 서명입니다.
- **오픈 소스와 수익** 허브는 관리형 컴퓨팅, 네트워크, 거버넌스, 지원에 요금을 받으며, 이는 자체 호스팅이 대신하지 못합니다.
- **창업자 한 명, 넓은 범위** 전략은 의도적으로 범위를 줄이고, 크레이트 개수가 아니라 재현 가능한 분석을 앞세웁니다.
- **규정 준수가 필요한 구매자** 규제 대상 고객에게는 SOC 2나 HIPAA가 필요합니다. 엔터프라이즈 단계에 계획되어 있습니다.
{% end %}

## 자금의 용도 {#what-funding-would-do}

{% tiles(cols=3) %}
1. **0개월에서 3개월** 원클릭 재실행과 diff를 갖춘 실행 기록, 출처 그래프, 브라우저와 서버에서의 Python, 그리고 세 곳에서 다섯 곳의 설계 파트너.
2. **3개월에서 6개월** GB 규모의 서버 컴퓨팅, 검토와 승인, 감사 내보내기, Nextflow와 Snakemake 가져오기, 그리고 첫 유료 팀.
3. **6개월에서 9개월** 두 노드에 걸친 페더레이션 재실행, 서명된 매니페스트, SSO, SOC 2로 가는 길, 그리고 공개된 코어 라이브러리.
{% end %}
