유럽에서 나가는 AI 요청 대부분은 외국 법률의 적용을 받는 데이터센터로 향하는 반면, 가까이 있는 성능 좋은 컴퓨터들은 하루 대부분을 놀고 있습니다. Archipelag.io는 실제로 동작하는 오픈 베타로, AI 작업을 가장 가까운 적합한 커뮤니티 컴퓨터로 보내고, 서명과 검토를 거친 모델 패키지만 실행하며, OpenAI API용으로 작성된 코드와 함께 동작합니다. 다음 단계는 호스트에 대한 실제 대금 지급, 데이터 소재지 요건이 있는 고객을 위한 지역 배치 강제, 그리고 스위스에서 시작하는 도시별 출시입니다.

## 문제 {#the-problem}

{% tiles(cols=3) %}
- **유럽의 개발자** 이미 사용하는 API 뒤에서 오픈 웨이트 모델을 쓰고, 작업이 실행되는 장소가 가까이 있고 명확하기를 원합니다. 지금은 프롬프트가 미국 하이퍼스케일러 리전으로 갑니다.
- **유휴 하드웨어를 가진 사람들** 게이밍 PC, Apple Silicon Mac, 채굴에 쓰이던 장비, 사무실 서버 등 이미 비용을 치렀지만 하루 대부분 쓰이지 않는 컴퓨팅 자원입니다.
- **그 사이의 공백** 탈중앙화 마켓은 결과를 제공하는 대신 머신 자체를 빌려주고, 호스트를 임의의 코드에 노출시키며, 신뢰성은 뒷전으로 둡니다.
{% end %}

## 제품 {#the-product}

{% tiles(cols=3) %}
- **OpenAI 호환 API** 스트리밍 채팅과 도구 호출을 웹, API, Python 및 JavaScript SDK, CLI를 통해 제공합니다.
- **Island** Rust로 작성된 호스트 에이전트로, Linux, macOS, Windows에서 실행되며 GPU 패스스루를 지원하는 Docker 또는 WebAssembly를 사용합니다.
- **가까운 곳 우선 배치** 코디네이터가 속도, 적합성, 여유 용량으로 호스트에 점수를 매기고, 같은 지역을 먼저, 그다음 인접 지역을 선호합니다.
- **서명된 Cargo만 실행** 호스트는 선별되고 서명된 모델 패키지를 샌드박스 안에서 실행합니다. 임의의 코드는 절대 실행하지 않습니다.
- **모든 작업의 기록** 각 작업을 어느 Island가 실행했는지 저장하므로, 실행 위치를 확인할 수 있습니다.
- **늘어나는 카탈로그** 채팅, 이미지, 임베딩용 오픈 모델을 제공하며, 2026년 10월부터는 도구를 사용하는 모델도 포함합니다.
{% end %}

오픈 베타는 2026년 3월부터 운영되고 있습니다. 무료이며, 계량(metering)을 검증하는 동안 호스트는 가상 크레딧을 받고, 실제 금전 지급은 아직 활성화되지 않았습니다.

## 시장 {#the-market}

분석 기관마다 이 시장을 다르게 정의하므로, 아래 수치는 맥락을 위한 것입니다. 가장 관련이 깊은 것은 추론 플랫폼 시장입니다. Archipelag.io는 GPU 시간이 아니라 결과를 판매하기 때문입니다. 그리고 유럽의 소버린 부문도 관련이 깊습니다.

{% tiles(cols=3, variant="figures") %}
- **1,060억 달러** 2025년 전 세계 AI 추론 시장 규모로, 2030년에는 2,550억 달러로 전망됩니다. [MarketsandMarkets](https://www.marketsandmarkets.com/PressReleases/ai-inference.asp)
- **188억 달러** 2025년 서비스형 AI 추론 플랫폼 시장 규모로, 매년 41퍼센트씩 성장해 2030년에는 1,050억 달러에 이를 전망입니다. [MarketsandMarkets](https://www.webull.com/news/13617937942971392)
- **69억 달러** 2025년 유럽 소버린 클라우드 인프라 시장 규모로, 2027년에는 231억 달러로 예상됩니다. [Gartner](https://www.gartner.com/en/newsroom/press-releases/2026-02-09-gartner-says-worldwide-sovereign-cloud-iaas-spending-will-total-us-dollars-80-billion-in-2026)
{% end %}

## 왜 지금인가 {#why-now}

{% tiles(cols=2, variant="figures") %}
- **+83 %** 2026년 유럽 소버린 클라우드 지출의 예상 성장률이며, 2027년에는 유럽이 북미를 앞지릅니다. [Gartner](https://www.gartner.com/en/newsroom/press-releases/2026-02-09-gartner-says-worldwide-sovereign-cloud-iaas-spending-will-total-us-dollars-80-billion-in-2026)
- **2,000억 유로** AI 컴퓨팅을 위한 EU의 InvestAI 계획입니다. 새 시설은 몇 년이 걸리지만, 가정과 사무실의 하드웨어는 오늘 이미 존재합니다. [Euronews](https://www.euronews.com/next/2025/02/11/eu-to-mobilise-200-billion-for-ai-investment)
- **“보장할 수 없다”** 프랑스 데이터가 미국 당국의 손이 닿지 않는 곳에 머무는지에 대한 Microsoft 법무 담당 이사 본인의 답변입니다. [The Register](https://www.theregister.com/2025/07/25/microsoft_admits_it_cannot_guarantee/)
- **오픈 웨이트** MIT 및 Apache 라이선스로 공개된 오픈 모델이 이제 최전선에 근접해 있으므로, 오픈 모델 카탈로그만으로 제품을 떠받칠 수 있습니다.
{% end %}

작은 모델도 계속 작아지고 있습니다. 수십억 개의 파라미터를 가진 모델이 이제 일반 노트북과 휴대폰에 들어가며, 이미 보급된 하드웨어의 더 많은 부분이 사용 가능한 공급이 됩니다.

## 차별점 {#what-sets-it-apart}

{% tiles(cols=2) %}
1. **머신이 아니라 결과** 고객은 이미 알고 있는 API를 호출합니다. 누구도 서버를 빌리거나 클러스터를 관리하지 않습니다.
2. **가까운 곳 우선** 배치는 호출자와 가까운 적합한 호스트를 선호하므로 지연 시간을 줄이고 작업을 현지에 머물게 합니다.
3. **호스트에게 안전** 레지스트리 허용 목록과 샌드박스 프로필 아래에서 서명되고 선별된 Cargo만 실행됩니다.
4. **휴대폰에서 서버까지** 다섯 개 플랫폼용 네이티브 빌드에 더해, iOS 및 Android 에이전트를 테스트하고 있습니다.
5. **토큰도 체인도 없음** 단순한 크레딧과, 이후에는 단순한 대금 지급뿐입니다. 고객과 결과 사이에 투기적인 요소가 없습니다.
{% end %}

## 비즈니스 모델 {#business-model}

{% tiles(cols=3) %}
- **고객용 크레딧** API 결과에 대한 사용량 기반 요금이며, 실행 기록이 제공되는 지역 제한 실행에는 프리미엄이 붙습니다.
- **호스트 대금 지급** 실제 작업 시간에 대해 지급하며, 신뢰할 수 있는 하드웨어와 밀집된 대도시권의 호스트에는 보너스를 줍니다.
- **컴퓨팅 거래소** 공급과 수요 사이의 시장 가격 결정으로, 이미 가상 크레딧으로 운영되고 있습니다.
{% end %}

시장 진입은 도시별로 진행합니다. 한 대도시권에 25개에서 50개의 호스트를 확보하고, 해당 지역에 클라우드 대체 수단을 유지하며, 데이터를 미국 리전으로 보낼 수 없는 스위스와 유럽 기업부터 시작합니다. 웹사이트에서는 맞춤형 모델 패키지를 위한 디자인 파트너를 모집하고 있습니다.

## 현재 위치 {#where-it-stands}

{% tiles(cols=3, variant="figures") %}
- **2026년 3월** 3월 13일부터 app.archipelag.io에서 무료 오픈 베타를 운영하고 있습니다.
- **v0.6** 2026년 10월의 Island 릴리스로, 도구 호출과 모든 네이티브 빌드에 포함된 llama.cpp 런타임을 갖추었습니다.
- **5** 네이티브 Island 빌드가 있는 데스크톱 및 서버 플랫폼 수이며, 모바일 에이전트도 테스트 중입니다.
{% end %}

Island 에이전트, CLI, 두 SDK, 웹사이트는 GitHub에 공개되어 있으며, Island는 MIT 라이선스를 따릅니다. 아직 유료 고객은 없습니다. 계량이 검증될 때까지 결제를 의도적으로 꺼 두었습니다.

## 위험 요소 {#risks}

{% tiles(cols=2) %}
- **불안정한 가정용 호스트** 작업이 실패하면 다시 대기열에 들어가고, 호스트는 평판을 쌓으며, 배치는 인접 지역으로 대체되고, 클라우드 대체 수단도 출시 계획에 포함되어 있습니다.
- **데이터 노출** 호스트는 신원이 확인되고 트래픽은 암호화됩니다. 규제 대상 구매자를 위한 기밀 추론은 프로토타입 단계이며 투자의 우선순위입니다.
- **데이터 소재지 주장** 현재 배치는 지역을 선호하는 수준입니다. 데이터 소재지를 약속하기 전에 엄격한 강제와 내보낼 수 있는 실행 기록을 먼저 갖추겠습니다.
- **자금력이 더 큰 경쟁자** 대부분은 토큰 네트워크이거나 미국 클라우드입니다. Archipelag.io는 토큰이 없다는 점, 유럽 중심의 포지셔닝, API를 통한 결과 제공으로 경쟁합니다.
{% end %}

## 투자금의 용도 {#what-funding-would-do}

{% tiles(cols=2) %}
1. **실제 대금 지급** 계량 검증을 마치고, 결제와 호스트 대금 지급을 켜고, 지급 규칙을 공개합니다.
2. **데이터 소재지 강제** 엄격한 지역 제한, 고객이 내보낼 수 있는 실행 기록, 그리고 제3자 보안 검토입니다.
3. **첫 번째 대도시권** 스위스의 한 도시에 25개에서 50개의 호스트를 확보하고, 지연 시간과 신뢰성 수치를 공개합니다.
4. **더 큰 모델** 대형 오픈 모델을 위한 다중 호스트 추론과 기밀 추론을 실험 단계에서 표준 기능으로 끌어올립니다.
5. **팀** 인프라 신뢰성, 보안, 개발자 관계 분야의 인력을 채용합니다.
{% end %}
